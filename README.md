## 📋 О проекте

Проект представляет собой набор автотестов для проверки корректности отображения и функциональности футера (подвала сайта) на различных страницах веб-сайта [Only.Digital](https://only.digital/).

### 🎯 Цели проекта:
- Проверить наличие футера на всех основных страницах сайта
- Убедиться в корректности отображения всех элементов футера
- Проверить адаптивность футера на разных разрешениях экрана
- Верифицировать работоспособность всех ссылок и кнопок

## 🏗️ Архитектура проекта

Проект построен с использованием современных паттернов автоматизации тестирования:

```
project/
├── conftest.py              # Конфигурация pytest и настройка логирования
├── tests/
│   ├── footer_tests.py      # Основные тесты футера
│   └── ...                  # Другие тестовые файлы
├── pages/
│   ├── base_page.py         # Базовый класс для страниц
│   └── main_page.py         # Класс главной страницы
├── utils/
│   └── locators.py          # Локаторы элементов (Page Objects)
├── requirements.txt         # Зависимости проекта
└── README.md               # Документация
```

## 🚀 Запуск тестов

### Базовый запуск всех тестов:
```bash
pytest tests/footer_test.py -v
```

### Запуск тестов для конкретной страницы:
```bash
# Тесты только для главной страницы
pytest tests/footer_test.py::TestMainFooter -v

# Тесты для страницы проектов
pytest tests/footer_test.py::TestProjectsFooter -v

# Тесты для страницы карьеры
pytest tests/footer_test.py::TestCareerFooter -v
```

### Запуск с дополнительными опциями:
```bash
# Запуск с детальным логированием
pytest tests/footer_test.py -v --log-level=DEBUG

# Запуск с созданием HTML отчета
pytest tests/footer_test.py -v --html=report.html

```

## 🎨 Особенности реализации

### 1. **Паттерн Page Object**
```python
# Пример использования Page Object
from utils.locators import FooterLocators

class TestMainFooter:
    def test_footer_presence(self, page):
        assert page.element_is_present(FooterLocators.ROOT)
```

### 2. **Наследование тестов**
- Базовые тесты в `TestMainFooter`
- Специфичные тесты для разных страниц наследуют общую функциональность
- Переопределение методов для страниц с другой структурой футера

### 3. **Адаптивное тестирование**
Тесты проверяют футер на 4 разрешениях экрана:
- Desktop (1920×1080)
- Laptop (1366×768)
- Tablet (768×1024)
- Mobile (375×667)

### 4. **Продвинутое логирование**
- Цветное форматирование в консоли
- Запись логов в файл с ротацией
- Детализированные сообщения об ошибках

## 📈 Логирование

Проект использует библиотеку Loguru для продвинутого логирования:

```python
# Пример лога
15:30:45 | INFO     | footer_tests:test_footer_presence:45 - Проверка наличия футера на странице
15:30:46 | SUCCESS  | footer_tests:test_footer_presence:48 - Футер успешно найден и видим
```

Логи сохраняются в:
- Консоль (цветное форматирование)
- Файл `test_results.log` (ротация 50 MB, хранение 10 дней)

## 🔧 Конфигурация

### Настройка в `conftest.py`:
- Глобальная фикстура для логирования
- Настройка формата вывода логов
- Обработчики для консоли и файла

### Параметры тестов:
- Неявное ожидание: 5 секунд
- Размер окна по умолчанию: 1300×1280
- Явные ожидания: до 10 секунд

## 🐛 Обработка ошибок

Тесты включают обработку различных исключений:
- `NoSuchElementException` - элемент не найден
- `TimeoutException` - превышено время ожидания
- `ElementNotVisibleException` - элемент не видим

## 🚨 Возможные проблемы и решения

### 1. **ChromeDriver не найден**
```bash
# Решение: убедитесь, что chromedriver в PATH
export PATH=$PATH:/path/to/chromedriver
```

### 2. **Ошибки при скролле**
```bash
# Решение: увеличьте время ожидания
self.driver.implicitly_wait(10)
```

### 3. **Элементы не находятся**
```bash
# Решение: проверьте актуальность локаторов в locators.py
# Обновите XPath/CSS селекторы при изменении верстки
```
